# 005. 1차는 조회 전용 (주문 없음)
- 날짜: 2026-10-07
- 상황: 분할매수는 토스 '주식 모으기' API로 하려 했다. 토스 공식 Open API(v1.2.19)에는 주식 모으기가 없다. 비공식 내부 API는 약관 위반 위험이 있다. 직접 구현하려면 국내는 정수 수량만 되고, 미국 금액 주문은 정규장~마감 1시간 전(한국 밤)에만 된다
- 결정: 1차에서 주문(수동 매수·매도, 분할매수 예약)을 전부 뺀다. 통합 잔고 조회만 만든다. 분할매수는 토스 앱 주식 모으기를 그대로 쓴다
- 따라오는 것: risk 패키지와 안전장치(002), 놓친 예약(003), live 모드는 보류. `Broker` 약속에 주문 메서드를 두지 않는다
- 다시 볼 때: 개별 종목 자동매매를 만들 때, 또는 토스가 주식 모으기 API를 열 때. 그때 002·003을 다시 검토하고 주문 안전장치부터 설계한다
- 출처: https://developers.tossinvest.com/llms.txt (openapi.json의 엔드포인트 목록)
