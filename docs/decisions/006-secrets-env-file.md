# 006. 비밀값은 프로젝트 폴더의 .env
- 날짜: 2026-10-07
- 상황: 처음에는 맥 키체인으로 정했다. 등록할 때 `security` 명령을 써야 해서 번거롭다
- 결정: 프로젝트 폴더의 `.env`에서 `EnvFileSecretStore`로 읽는다. 한 줄에 `이름=값` (예: `toss.client-id=...`), `#`은 주석
- 지키는 장치
  - `.env`는 `.gitignore`에 있다. 빠지면 `GitIgnoreTest`가 실패한다
  - Claude는 `.env`를 열지 못한다: Read 도구는 `.claude/settings.json`이, 셸 명령은 `.claude/hooks/block-live.sh`가 막는다
  - 환경변수는 여전히 쓰지 않는다 (구조 시험). 파일을 직접 읽는다
- 받아들인 위험
  - 저장소가 공개라서, `.gitignore`를 우회하는 실수(`git add -f` 등)를 하면 키가 바로 공개된다. 그런 일이 생기면 토스 WTS에서 키를 곧바로 재발급한다
  - 키체인과 달리 암호화되지 않는다. 내 계정으로 도는 프로그램은 모두 읽을 수 있다. 권한은 `chmod 600 .env`로 나만 읽게 둔다
- 버린 대안: 맥 키체인(더 안전하지만 등록이 번거로움), 저장소 밖 `.env`(커밋 사고는 없지만 경로를 따로 관리해야 함)
