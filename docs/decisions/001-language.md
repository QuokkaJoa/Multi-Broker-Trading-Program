# 001. 언어: Java + Spring Boot
- 날짜: 2026-10-07
- 상황: 자동화 도구는 Python을 많이 쓰지만, 내가 읽고 이해할 수 있는 건 Java
- 결정: Java(최신 LTS) + Spring Boot(최신 안정판) + Gradle. 정확한 버전은 0단계에서 정하고 여기에 적는다
- 이유: 이 프로그램은 대부분 증권사 응답을 기다리는 시간이라 언어 성능 차이가 의미 없다. 내가 코드를 읽고 설명할 수 있는 게 더 중요하다
- 버린 대안: Python — 증권사 관련 도구는 더 많지만 내가 검토하기 어렵다. Python·Go로 된 공개 도구는 참고서로만 쓴다
- 확인한 사실 (2026-10-07): 최신 LTS는 Java 25 (27은 LTS 아님, 다음 LTS는 29·2027-09). Spring Boot 최신 안정판 4.1.1
