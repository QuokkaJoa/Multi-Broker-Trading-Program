# 002. 안전장치: 금액 상한 없이, 고장 방지 4가지
- 날짜: 2026-10-07
- 상태: 보류 — 1차는 조회 전용이라 쓰지 않는다 (005). 주문을 다시 넣을 때 다시 검토한다
- 상황: 투자 금액 한도는 두지 않는다. 투자 판단은 내가 한다
- 결정: 대신 프로그램 고장을 막는 4가지만 둔다
  1. 같은 예약은 하루 한 번만 — 예약ID+날짜로 중복 차단, 증권사가 지원하면 주문 고유번호도 쓴다
  2. 예약에 적은 종목·금액과 다른 주문은 차단 — 수동 주문은 확인 단계에서 금액을 다시 보여준 뒤 보낸다
  3. 비상정지 — 켜면 예약·수동 모든 주문이 멈춘다. 재시작해도 상태가 유지된다
  4. 실전(live)은 사람만 켠다
- 이유: 막으려는 건 시장 위험이 아니라 내 프로그램의 실수(같은 예약 반복 실행, 금액 단위 착오)다
