# 키움증권
출처: https://openapi.kiwoom.com/intro/serviceInfo , https://github.com/Kiwoom-Securities/Kiwoom-REST-API (2026-10-07 확인)

- 앱키 발급 전에 허용 IP를 등록해야 한다 (최대 10개). 그 밖의 IP에서는 인증이 안 된다
- 접근 토큰 유효기간 24시간
- 실전과 모의투자의 앱키가 따로다. 모의투자는 따로 신청한다
- 실전·모의 각각 계좌를 20개까지 추가 등록할 수 있다. 계좌(위탁/ISA 등)와 HTS ID 연결 필요
- 모의투자는 실제 계좌와 별개인 가상 계좌다 (상시모의투자, 국내주식·미국주식만). 출처: https://openapi.kiwoom.com/intro/mockInvestInfo (2026-10-07 확인)
  → 모의투자에는 ISA가 없다고 보는 게 맞다 (공개 문서에 ISA 언급 없음). 2단계 모의 조회는 일반 모의 계좌로 응답 모양만 확인한다
- ISA 계좌의 REST 조회: 공개 문서(이용안내·모의투자 안내·자주묻는질문·공식 GitHub)에 ISA 언급이 없다 (2026-10-07 확인)
  - 포털 '계좌 등록하기'에 일반 계좌와 ISA 계좌 둘 다 등록되어 있다 (2026-10-07, 사람이 확인). 등록은 된다
  - 잔고·보유 조회가 실제로 ISA에서 되는지는 2단계 dryrun 첫 조회(사람이 실행)로 확인한다
- 집 공인 IP가 바뀐다. 바뀌면 사람이 포털에서 IP를 다시 등록한다 (2026-10-07 결정). 그동안 키움 조회는 실패하고, 통합 잔고는 `failedBrokers`로 알린다
- 모름: 호출 한도, 주문 중복 방지 키
