# 2단계: 키움 ISA 조회 + 통합 잔고 + 슬랙 알림

## 목표
키움 ISA 계좌의 예수금·보유를 dryrun으로 실제 조회해, 1단계 첫 화면에 토스와 함께 원화 합산으로 보여준다.
두 번째 증권사로 `Broker` 약속이 그대로 맞는지 확인한다 (한 증권사 사정으로 약속을 휘게 하지 않는다).
조회 오류(허용 IP 차단·키 틀림 등)는 슬랙으로 알린다.
숫자는 키움 앱과 맞는다 (원화 원 단위 — product.md 성공 기준).
