# 전체 단계

규칙: 자세한 계획서는 각 단계를 시작할 때 `plans/active`에 쓴다. 끝나면 `plans/done`으로 옮긴다.

- 0단계 뼈대 — 가짜 증권사로 조회가 끝까지 돈다 (완료 2026-10-07, plans/done/phase-0-skeleton.md)
- 1단계 토스 조회 + 실시간 첫 화면 — 토스 종합매매 계좌 잔고·보유를 dryrun으로 조회해 화면에 보여준다. 평가금은 웹소켓 체결가로 실시간 (plans/active/phase-1-read.md).
  키체인 SecretStore 연결, networkTest(사람만 실행), 화면 기술은 decisions/004
- 2단계 키움 ISA 조회 + 통합 잔고 — 키움 모의투자 → dryrun 조회, 원/달러 합산.
  두 번째 증권사로 공통 약속이 맞는지 검증. 슬랙 알림(조회 오류)

## 보류 (주문을 다시 넣을 때, decisions/005)
- 3단계 수동 주문 — 키움은 모의투자로 실제 주문, 토스는 dryrun(기록만). 주문 확인 단계, 슬랙 알림(체결·오류)
- 4단계 분할매수 예약 — 예약 켜기·끄기, 놓친 예약(슬랙 알림 + 화면에서 선택), 실행 중 맥이 잠들지 않게, 미국 주식 낮 예약 주문 가능 여부 확인
- 5단계 실전 소액 — 사람이 live를 켜고 소액으로 각 기능 확인
