# 증권사 추가 절차
1. 공식 문서와 참고 코드를 읽고 `docs/brokers/<증권사>.md`에 인증 방식·호출 한도·모의투자 여부·함정을 정리한다. 사용자가 참고 저장소 경로를 주면 해당 증권사 부분을 읽고 동작 방식을 따라 만든다
2. contract 시험이 새 어댑터로 실패하는 걸 먼저 확인한다 (red)
3. 조회를 구현해 시험을 통과시킨다 (green). 주문은 만들지 않는다 (decisions/005)
4. 실서버 녹화가 필요하면 사람에게 `./gradlew networkTest` 실행을 요청한다. 직접 실서버를 부르지 않는다
5. 구조 시험 포함 `./gradlew test` 통과
6. 끝나면 바뀐 것 요약과, 이 증권사 연결의 핵심을 담은 짧은 노트 초안(개인 보관용)을 만든다
