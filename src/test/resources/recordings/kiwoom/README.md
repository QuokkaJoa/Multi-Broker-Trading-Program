키움 녹화 응답. 공식 명세(Kiwoom-REST-API `kiwoom_api_spec.json`, 2026-10-15 받음)의 예시 값 그대로다. 실서버 응답은 여기에 두지 않는다 (계획서 "공개 저장소라서 지킬 것").
파일 이름은 TR 코드(`api-id` 헤더 값)다.
`au10001.json`·`ka00001.json`은 명세 예시에 쉼표가 빠져 있어(`"token":"…"` 다음 줄) 쉼표만 넣었다.
`kt00018.json`은 같은 종목(`A005930`)이 두 줄이다. 두 줄 모두 `crd_tp` "00"이고 현재가가 서로 달라 실제 모양이라기보다 예시를 대충 만든 것으로 보인다. "여러 줄은 합친다" 시험에 쓴다.
`error-*.json`은 명세에 오류 응답 예시가 없어, 정상 응답의 `return_code`·`return_msg` 모양에 오류코드 표의 코드·문구를 넣어 만들었다 (`{?}`도 표 그대로). 실제 모양은 2단계 항목 6의 실서버 시험에서 본다.
